## 🐛 QUICK TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| Batch file won't run | Right-click → Open with → Command Prompt |
| Backend won't start | Wait 1-2 min (first run downloads Maven) |
| Frontend won't start | Ensure Node.js is installed |
| Port 8080 busy | `taskkill /PID <number> /F` |
| Port 4200 busy | `taskkill /PID <number> /F` |
| "Cannot connect" | Both servers must be running |

More help in: STARTUP_GUIDE.md
